# Лицензирование содержания школьных учебников

Исследование для фичи «решение по номеру задачи».
Дата: 2026-08-30. Составлено на основе открытых источников.

> **Дисклеймер.** Это аналитическая справка, а не юридическое заключение.
> Никаких гарантий правового результата не даётся. Перед любыми переговорами
> и перед запуском монетизации требуется консультация практикующего юриста
> по интеллектуальной собственности.

## Исходные данные

| Параметр | Значение |
|---|---|
| Модель | Платный сервис: ученик выбирает учебник → вводит номер задачи → получает решение |
| Цена | 5–15 ₽ за решение (использование **коммерческое**) |
| Что в базе | 1431 условие, OCR из «Геометрия 7–9», Атанасян Л.С. и др., 14-е изд., «Просвещение», 2023 |
| Статус PDF | Исходные PDF с сайта убраны |
| Владелец | Самозанятый; домен и личность устанавливаются тривиально |
| Главный вопрос | Можно ли легально купить право использовать содержание учебников |
