# Конкуренты и правовой ландшафт: ГДЗ-сервисы, условия задач, блокировки

Дата исследования: 29 августа 2026.
Автор: продуктовый аналитик (исследование по открытым источникам).

**Это не юридическое заключение.** Ниже — фактура из открытых источников и продуктовые выводы. Ни одна рекомендация здесь не является гарантией того, что сервис не заблокируют или к нему не предъявят иск. Перед запуском платной выдачи по номерам нужна проверка практикующим юристом по интеллектуальной собственности.

Контекст на момент исследования: сканы учебников с сайта уже убраны, есть аварийный выключатель выдачи индекса; в базе остаётся 1431 распознанное условие из одного учебника геометрии (Атанасян 7–9); сервис платный, владелец и домен устанавливаются тривиально, оформлена самозанятость.

**Главная закономерность таблицы:** все, кто показывает текст условия из чужого учебника, делают это либо по прямому договору с издательством (ЯКласс, Chegg до 2021), либо без всяких прав и под риском блокировки (gdz.ru и его окружение). Все, кто хочет работать без договора и без риска — либо пишут свои задачи (Учи.ру, Фоксфорд, РЭШ), либо получают условие от самого ученика (Photomath, Gauth, основной сценарий Skysmart Решения). Промежуточной легальной ниши «мы сами оцифровали чужой учебник и показываем условия» в найденной практике нет.
